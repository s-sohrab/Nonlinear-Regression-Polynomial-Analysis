#  Nonlinear Regression: Polynomial Analysis & Deployment

##  Project Overview
This repository contains a comprehensive, production-ready implementation of **Polynomial Regression** to model a non-linear (sinusoidal) relationship between time and bacterial population. The project goes beyond basic model fitting by incorporating **reproducibility**, **train/test splitting**, **5-fold cross-validation**, **hyperparameter tuning**, and **interactive deployment** via Gradio.

The goal is to demonstrate how polynomial feature expansion transforms a linear model into a powerful tool for capturing complex, non-linear dynamics, while critically managing the **bias-variance trade-off** to prevent overfitting.

##  Problem Statement
Given synthetic data generated by the function \( y = 1000 \sin(0.1x) + \varepsilon \), where \(\varepsilon\) is Gaussian noise (\(\mu=0, \sigma=50\)), we aim to predict the population \(y\) based on time \(x\). A simple linear regression fails to capture the sinusoidal nature; hence, polynomial expansion is employed.

## 🛠️ Methodology & Engineering Highlights
1.  **Reproducible Data Generation**: 100 data points generated using NumPy with a fixed random seed (`42`) to ensure exact reproducibility.
2.  **Polynomial Expansion**: `PolynomialFeatures` from scikit-learn is used to transform the input \(x\) into higher-degree terms (\(x^2, x^3, \dots\)).
3.  **Pipeline Architecture**: A `Pipeline` combining `PolynomialFeatures` and `LinearRegression` is implemented. This ensures proper data handling, prevents data leakage, and makes the code modular.
4.  **Robust Evaluation**: The model is evaluated on a **held-out test set** (20% of data) using MSE and R² metrics, providing an unbiased estimate of generalization performance.
5.  **Cross-Validation**: 5-Fold Cross-Validation is performed to assess model stability and variance across different subsets of the data.
6.  **Overfitting Analysis**: Model performance is systematically compared across degrees (1, 2, 3, 5, 10, 15) on both training and test sets to identify the optimal complexity.
7.  **Hyperparameter Tuning**: `GridSearchCV` is used to systematically search for the optimal polynomial degree (1 through 7), ensuring the final model is selected based on empirical evidence rather than guesswork.
8.  **Interactive Deployment**: The final optimized model (Degree 5) is deployed using **Gradio**, allowing users to interact with the model via a simple UI slider.

##  Key Results
- **Optimal Degree**: **5** (Selected via `GridSearchCV` with 5-fold CV).
- **Test MSE (Degree 5)**: ~1,609.56
- **Test R² (Degree 5)**: ~0.9863
- **Overfitting Insight**: Degrees ≥ 10 exhibit a widening gap between training and test MSE, confirming the onset of overfitting. The degree-5 model provides the optimal balance between model complexity and generalization.

## 💻 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/s-sohrab/Nonlinear-Regression-Polynomial-Analysis.git
   cd Nonlinear-Regression-Polynomial-Analysis
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

